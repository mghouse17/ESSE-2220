# Lab 7: Detecting Features in Space (SIFT & ORB)

This lab uses OpenCV to detect and visualize image features with Scale-Invariant Feature Transform (SIFT) and Oriented FAST and Rotated BRIEF (ORB).

The project includes:

- SIFT and ORB keypoint detection
- Visualization of the 50 strongest keypoints
- Comparison of SIFT and ORB descriptors
- A descriptor-vector plot
- The completed report and LaTeX source

## Run

Install the dependencies:

```bash
pip install -r requirements.txt
```

Place the required input image, `space.jpg`, in this directory, then run:

```bash
python lab7sourcecode.py
```

The original archive did not include `space.jpg`; the generated output images are included for reference.
